# AnySolvers IM

Install from the pinned plugin release branch/tag in https://github.com/OneFav/anysolvers-next .

Ask your installation agent to follow [INSTALL.md](https://github.com/OneFav/anysolvers-next/blob/main/INSTALL.md) for the independent backend. Set this bundle's `instance` configuration to the instance directory, or set `ANYSOLVERS_INSTANCE` before starting DSH. Credentials and research data never live inside this plugin. Closing DSH does not stop services.
