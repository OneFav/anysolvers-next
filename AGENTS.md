# AnySolvers Next

This is the independent next version. Never edit the source projects AnySolvers-dsh or anysolvers-plugin, their runs, installed profiles or credentials.

Three independent stage workers own initialization (task/datasets/ideas), research (research/evaluation/selections), and terminal delivery (final/visualization). Only the research method creates researcher subagents. Router handles human communication and orchestration. Framework workers and autonomous harness edits are prohibited. Workers may report defects only; framework maintenance is a separate, explicitly authorized developer task.

Preserve complete modules/<category>/<method> packages. Candidates and baselines execute only in the accounted evaluator. The framework and native DSH researcher workspaces run locally; when configured for compute-node, computation/evaluation defaults to SSH and resource-limited remote Python processes, without Docker. This remote process backend has no filesystem/network sandbox; do not describe local DSH confinement as protecting remote execution. Record the actual resource enforcement honestly. Legacy sealed batches retain their original backend and evidence. Final data/results never return to research. Freeze initialization and implementation identity; use a new version/run for changes.

No token quota accounting. Persist provider-unavailability incidents and resume after verified recovery. Unknown evaluations block replay. Context subscriptions grant no execution authority. Existing projects default to read-only monitoring.

Tests must distinguish deterministic fixtures, real OS processes, native DSH sessions, actual model calls and actual sandbox evaluation. Never report a simulated test as real research. Live Feishu delivery requires a designated test group; never read or print credentials. No global installation.
